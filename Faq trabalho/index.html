HTML

O que é HTML?

é a linguagem usada para estruturar o conteúdo de páginas da web, como textos, imagens e links. Ele define a organização dos elementos que os navegadores exibem na internet.

HTML é linguagem de programação?

Não. HTML não é uma linguagem de programação, porque não executa lógica, cálculos ou tomadas de decisão. HTML é uma linguagem de marcação, usada para estruturar e organizar o conteúdo de páginas web. Para programação, geralmente usa-se JavaScript junto com HTML e CSS.

Para que serve o HTML?

O HTML serve para estruturar o conteúdo de páginas da web, definindo elementos como títulos, parágrafos, imagens, links, tabelas e formulários.

O que são tags HTML e qual a função delas em uma página web?

As tags HTML são elementos escritos entre sinais de menor e maior (< >) que definem a estrutura e o significado do conteúdo de uma página web.

Como inserir uma imagem e um link em uma página HTML?

Uma imagem é inserida com a tag , usando o atributo src para indicar o endereço da imagem. Um link é criado com a tag , usando o atributo href para definir o destino.

PHP

O que é PHP?

PHP é uma linguagem de programação voltada para o desenvolvimento web, usada principalmente para criar páginas dinâmicas e interagir com bancos de dados.

Como o PHP é executado em um servidor web?

O PHP é executado no servidor web, antes da página chegar ao navegador do usuário.

O que são variáveis em PHP e como elas são declaradas?

Variáveis em PHP são espaços na memória usados para armazenar valores, como textos, números ou resultados de operações, que podem ser usados e alterados durante a execução do programa.

Quais são os principais tipos de dados utilizados em PHP?

Os principais tipos de dados em PHP são: String: texto, como "Olá mundo". Integer (int): números inteiros, como 10 ou -5. Float (double): números com casas decimais, como 3.14. Boolean (bool): valores lógicos true ou false.

Como criar uma estrutura de decisão usando if em PHP?

Em PHP, uma estrutura de decisão com if é usada para executar um bloco de código apenas quando uma condição for verdadeira.

Javascript

O que é Javascript?

JavaScript é uma linguagem de programação usada principalmente para criar interatividade em páginas da web.

O que o Javascript consegue fazer?

O JavaScript consegue adicionar interatividade e dinamismo às páginas da web.

Javascript funciona apenas no navegador?

Não. O JavaScript começou e ainda é muito usado no navegador, mas não funciona apenas nele.
